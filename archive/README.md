# Earlier releases

Each folder here holds what an earlier BenchProctor release published and a later one replaced,
unchanged: its cases, answer keys, scorers, manifests, and a `SHASUMS256.txt` over every file it
holds. A release of some languages only replaces only their folders, so an archived release holds
exactly the folders that were replaced. The current release is in [`Benchmarks/`](../Benchmarks).

| Release | Status | Notes |
|---|---|---|
| [2026.11.19](2026.11.19) | C and C++ superseded by 2026.11.19.1 | Holds the 2026.11.19 C (640 cases) and C++ (1,520 cases) folders. The other nine languages and the applications of 2026.11.19 are still current, in `Benchmarks/`. |
| [2026.11.16](2026.11.16) | Superseded by 2026.11.19 | Published as one zip per bundle; kept here unpacked. The original zips are in this repository's history. |

Release 2026.07.22 is withdrawn and is not kept here; see the README's [Corrections and ground-truth disputes](../README.md#corrections-and-ground-truth-disputes).
