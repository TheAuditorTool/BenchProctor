# Roadmap

Release 2026.11.19 is the current release: 14,280 standalone cases in all 11 languages across 21
framework targets, and 368 multi-service applications in five languages, published as plain files.
Earlier releases are kept under [`archive/`](archive/).

Releases are curated. Each one is a fresh draw with the same languages, frameworks, weakness
classes and difficulty, so scores stay comparable from one release to the next. The
larger corpus the releases are drawn from is not published.

The next release is planned as a quarterly rotation of this one. See [README.md](README.md) for
what a release contains and [changelog.md](changelog.md) for the history.
